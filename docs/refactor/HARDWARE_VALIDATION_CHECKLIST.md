# 硬件验证清单

以下项目未在本次无硬件环境中验证，统一为 `HARDWARE_VALIDATION_PENDING`。

## 启动和电源

- [ ] 上电、软复位、掉电重启、棕断场景启动正常。
- [ ] 初始化顺序无外设毛刺；IWDG 约束和复位原因符合产品要求。
- [ ] 主循环 `__WFI` 唤醒、功耗和任务抖动符合历史固件。

## 超声波

- [ ] 逻辑分析仪比较 PA1/PA2/PA7/PA8 正反向激励序列、电平极性、脉冲数和 12.5 µs 延时。
- [ ] 比较 SysTick、USART RX、全局中断与 TIM14 捕获的开关顺序。
- [ ] PA4 双边沿捕获、最低波值、溢出和 24 次终止行为。
- [ ] 左右飞行时间、波形对齐、Ff/Fb 在空气、氧气和量程流量下与基线固件一致。

## 传感器与算法精度

- [ ] NTC 在 -30..80 ℃ 边界和断路/短路条件下读取一致。
- [ ] 两颗 LQTP 软件 I2C 地址/引脚切换、系数读取、温压换算和异常状态。
- [ ] GXHT40 当前禁用状态保持；若未来启用，验证 CRC 和湿度箱性能。
- [ ] 氧浓度空气点、量程点、温度点、0/120% 限幅和启动 12 点行为。
- [ ] 流量所有分段边界、零流、正/负阶跃、背压和环境压力补偿。
- [ ] 确认压力尚未有效时除零的实际 ARMCC/目标表现。

## 通信、Flash 和输出

- [ ] 9600/38400/115200 波特率及上电选择。
- [ ] UART 典型命令、错误帧、连续帧、粘连/截断/溢出和自动上报时序。
- [ ] 真实历史设备标定数据在页 30/31 轮换后仍可读取。
- [ ] 擦写中断电、计数回绕、单页损坏、两页空白恢复。
- [ ] O2/FLOW PWM 引脚、1 kHz、占空比和模拟滤波后电压。
- [ ] 红/黄/绿/运行 LED 极性、阈值和迟滞。

## 资源和发布

- [ ] 使用 ARMCC 5.06u7 完整重建，比较关键函数反汇编。
- [ ] 在相同优化选项下记录 ROM/RAM 与栈余量。
- [ ] 烧录最终 HEX/BIN，至少执行一轮老化和校准数据回读。
- [ ] 产品级精度、EMC、温湿度、压力和流量台架回归。

完成这些项目之前，不得声称产品验证通过、时序完全一致、测量精度完全一致或可直接量产。
